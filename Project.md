### Site Colors Setup

Based on your current portfolio structure, here is how you should map these variables to your components:

#### Global Background (body)

- Use `bg-surface`
- Creates the "base paper" or "night sky" canvas

#### Navigation & Footer

- Use `bg-surface-soft`
- Subtly separates the header and footer from the main content without using harsh borders

#### Cards (Projects/Skills)

- Use `bg-surface-soft`
- **Light Mode effect**: Makes the cards look like thicker layers of paper
- **Dark Mode effect**: Provides a "glow" effect where cards look closer to the viewer

#### Headings (h1, h2, h3)

- Use `text-text-main`
- Provides the highest contrast for readability

#### Subtitles & Dates

- Use `text-text-muted`
- Lowers the visual hierarchy for less important information

#### Call-to-Action (Buttons/Links)

- Use `bg-accent text-surface` for primary buttons
- **Light Mode**: Looks like a leather bookmark or stamp
- **Dark Mode**: Looks like a glowing moon-lit button

#### Icons & Decorative Lines

- Use `border-accent` or `text-accent`
